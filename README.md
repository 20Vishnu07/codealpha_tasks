# CodeAlpha AI Projects

A collection of three practical AI and machine-learning projects completed during the CodeAlpha internship program.

## Projects

| Project | Description | Main technologies |
| --- | --- | --- |
| [CodeAlpha_FAQChatbot](CodeAlpha_FAQChatbot) | FAQ matching chatbot with TF-IDF and cosine similarity. | Python, NLTK, scikit-learn, Flask |
| [CodeAlpha_ObjectTracking](CodeAlpha_ObjectTracking) | Real-time object detection and multi-object tracking. | Python, YOLOv8, SORT, OpenCV |
| [CodeAlpha_TranslationTool](CodeAlpha_TranslationTool) | Browser-based text translation with language selection and speech output. | Python, Flask, deep-translator |

Each project contains its own README, dependency file, and runnable entry point.

## Repository structure

```text
CodeAlpha_FAQChatbot/
CodeAlpha_ObjectTracking/
CodeAlpha_TranslationTool/
```

## Getting started

Choose a project, read its README, install its `requirements.txt`, and run the documented command. Projects are intentionally independent and can be developed separately.
